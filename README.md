## 线路走向：GIA 全程 59.43，GT 国内段 202.97

CN2 是中国电信在 163 骨干网之外另建的一张承载网，AS 号 4809，骨干节点 IP 以 59.43 开头；老的 163 骨干网是 AS4134，节点 IP 以 202.97 开头。163 承担了电信约九成的海外出口业务量，回国方向一堵，走 163 的机器集体变慢，这也是全 163 机房这几年表现越来越差的原因。

GIA 与 GT 的差别在通道等级，跟机房位置无关。同一个机柜里的两台机器，卖的可能就是两种通道。

GIA：省内 59.43 → 出境 59.43 → 海外机房，回程原路 59.43 返回。

GT：省内 202.97 → 国际出口切 59.43 → 海外机房，回程出了国际段又回到 202.97。

GIA 有独立的回国线路，在电信骨干网里拿最高一级 QoS，晚高峰拥塞时它的流量优先放行。GT 没有自己的中国出口，和 163 共享出口带宽，路由里能看到成片的 202.97。

省级接入的细节更值得看。GIA 用户如果本省有 CN2 节点，流量在省内就直接上 59.43；本省没有节点，才就近接北上广的 202.97，再从那里进 59.43 出境。江苏南通的用户本省有南京节点，GIA 在南京就接上了 59.43，之后从上海出口；安徽芜湖没有本省节点，先到上海 202.97，再进 59.43。同样一段南京到上海，GT 走 202.97，GIA 已经是 59.43。

## 怎么验证商家给的是不是真 GIA

不用信宣传页，一条命令就能看出来。Windows 用 `tracert 目标IP`，Linux 和 macOS 用 `mtr -rn 目标IP`，mtr 连着跑几分钟比单次 traceroute 可靠，还能看到每一跳的丢包率。

判断规则只有三条：

1. 全程都是 202.97 开头的节点，说明走的是普通 163，没有 CN2。
2. 国际段出现 59.43，进入国内变回 202.97，是 CN2 GT。
3. 省级段就是 59.43，整条路径出现 4 个以上 59.43 节点，是 CN2 GIA。GT 一般只有 2 到 3 个 59.43，省级段会切回 202.97。

还有一类要单独提：去程走 59.43、回程全走 202.97 的“伪 CN2”。去程好看，回程才是你下载和打开网页的方向，这类线路的实际体验打折最狠。测回程要在海外服务器上向你的公网 IP 跑 mtr，方向别搞反。

测试时间挑晚高峰，平峰测出来的结果都好看。想省事，就先看商家有没有提供测试 IP 或 Looking Glass，拿测试 IP 自己跑一遍，比看任何测评都直接。
